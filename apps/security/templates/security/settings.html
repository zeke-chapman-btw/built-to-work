Backups

Database: Render keeps a continuous backup and can restore the database to any minute in the last 7 days (Render → btw-preview-db → Recovery → Restore database). You can also download a full copy any time with Create export on the same page.

Uploaded files (W-9s, documents, consents, imports) live on the app's disk, which Render snapshots once a day and keeps for 7 days (Render → btw-preview → Disks → Snapshots).
